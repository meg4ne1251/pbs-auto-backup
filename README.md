# PBS 自動起動・停止

Proxmox Backup Server（PBS）を、バックアップと保守に必要な時間だけ稼働させるためのプロジェクトです。常時稼働する Proxmox VE（PVE）から Wake on LAN で PBS を起動し、処理状況を確認して安全に停止する構成を検討しています。

> **導入時の注意:** 実機の値とコマンド出力を確認してから cron を有効にしてください。環境固有の設定と検証記録はリポジトリに含めません。

## 設計の概要

- PVE の既存の定期バックアップジョブを利用し、このプロジェクトからバックアップの開始や再実行はしません。
- PBS の起動には Wake on LAN を使い、SSH、PBS サービス、ストレージの状態を確認してから準備完了とします。
- PBS の実行中タスクや対象ストレージの保守処理を監視します。状態を取得できない場合は停止を保留します。
- 停止条件を連続して確認した後、SSH 経由で正常なシャットダウンを要求します。強制電源断は行いません。

時刻、待機上限、監視の引き継ぎ、失敗時の扱いを含む詳細は [設計書](docs/design.md) を参照してください。設計書の値は現時点の想定であり、実機への導入前に環境に合わせて確認する必要があります。

## 実装

- PVE: [pve_controller.py](pve_controller.py) — WOL、起動準備確認、停止監視、翌日への引き継ぎ。
- PBS: [pbs_agent.py](pbs_agent.py) — datastore と ZFS の確認、実行中タスクの確認、正常なシャットダウン。
- 設定例: [PVE](config/pve.example.json) / [PBS](config/pbs.example.json)。
- 導入・検証方法: [docs/setup.md](docs/setup.md)。

実機ごとの確認項目と cron 登録手順は [導入手順](docs/setup.md) を参照してください。

ホスト名、IP・MAC アドレス、SSH 秘密鍵、認証情報などの実環境の値はリポジトリに含めないでください。
